# Advent of Code - Haskell

A Haskell template for Advent of Code.

## Getting Started

Refer to the repository's shared [flake.nix](../../../../flake.nix) for the packages needed to compile this project. If
you have `nix`, run `nix develop .#haskell` from anywhere inside the repository to enter a dev shell with all of the
dependencies installed.

## Useful Commands

- Build and run:

  ```shell
  just run
  ```

- Run tests:

  ```shell
  just test
  ```

- Benchmark:

  ```shell
  just benchmark
  ```

- Format the entire project:

  ```shell
  just fmt
  ```
